초등학교 4학년을 위한 완벽한 아두이노 학습 플랫폼

⚙️ 아두이노란?

아두이노는 오픈소스 전자 프로토타이핑 플랫폼이에요. 간단한 프로그래밍으로 LED를 제어하고, 센서로 데이터를 읽고, 로봇을 움직일 수 있어요!

🔧 필수 부품

마이크로컨트롤러: Arduino Uno

기본 부품: 브레드보드, LED, 저항, 센서

연결 도구: 점프 와이어, USB 케이블

💡 모든 부품은 저희 자판기에서 구매할 수 있어요!

💻 코딩 기초

아두이노 코드는 C언어와 비슷해요.

Arduino Code 
void setup() {
  // 처음 한 번만 실행
}

void loop() {
  // 계속 반복 실행
}

⚡ 전압 이해하기

5V: Arduino의 전원 전압

0V (GND): 접지 (기준점)

HIGH: 5V 신호

LOW: 0V 신호

🚀 심화 아두이노

기초를 다졌다면 이제 한 단계 더 나아가볼까요? 더 복잡한 개념들을 배워봐요!

⏱️ millis()로 여러 작업 동시에

심화

delay() 대신 millis()를 사용하면 LED를 깜빡이면서 동시에 버튼도 확인할 수 있어요! (블로킹 없는 코드)

🔀 상태 머신 (State Machine)

심화

여러 상태(대기, 동작, 알람)를 switch문으로 관리하는 방법을 배워요. 복잡한 로봇 제어에 필수!

📡 I2C 다중 센서 통신

심화

Wire 라이브러리로 여러 개의 I2C 센서를 동시에 연결하고 각각 주소로 구분해서 읽어요.

💾 EEPROM 데이터 저장

심화

전원이 꺼져도 데이터가 남아있게 하려면? EEPROM에 설정값을 저장하고 불러오는 방법을 배워요.

🌐 WiFi로 데이터 전송

심화

ESP8266/ESP32 보드로 센서 데이터를 인터넷 서버에 보내는 IoT 프로젝트의 기초를 배워요.

⚡ 인터럽트로 즉각 반응

심화

attachInterrupt()로 버튼이 눌리는 순간 바로 반응하는 코드를 만들어요. loop()를 기다릴 필요 없어요!
